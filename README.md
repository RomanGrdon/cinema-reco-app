## 📌 Contexte

Ce projet a été développé dans le cadre de ma formation en Data & IA.  
Il s'agit d’un système de recommandation de films utilisant l’algorithme **K-Nearest Neighbors (KNN)**.

L’objectif est de démontrer comment un modèle de Machine Learning peut être utilisé pour générer des recommandations pertinentes à partir de données utilisateur.

---

## 🎯 Objectif du projet

Construire un système capable de :

- Recommander des films similaires à partir d’un film sélectionné
- Implémenter un algorithme de similarité (KNN)
- Transformer un modèle ML en application interactive exploitable

---

## 🧠 Méthodologie

### 1️⃣ Préparation des données
- Nettoyage et structuration du dataset
- Sélection des features pertinentes
- Vectorisation des données

### 2️⃣ Modélisation
- Implémentation de l’algorithme **KNN**
- Calcul des distances pour identifier les films similaires
- Optimisation du nombre de voisins

### 3️⃣ Déploiement
- Création d’une interface avec **Streamlit**
- Intégration du modèle dans une application interactive
- Déploiement en ligne

---

## 🚀 Fonctionnement

1. L’utilisateur sélectionne un film.
2. Le modèle calcule les films les plus proches selon la similarité.
3. L’application affiche une liste de recommandations pertinentes.
